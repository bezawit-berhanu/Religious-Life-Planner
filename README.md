# Orthodox Life App

## Overview

**Orthodox Life** is a digital companion designed to help users stay connected with the spiritual practices of the Orthodox Christian faith. The app provides tools that support daily prayer, reflection, and spiritual discipline.

The goal of the project is to make it easier for Orthodox believers to integrate faith practices into everyday life through a clean, modern, and accessible digital interface.

## Features

* **Daily Dashboard:** Track fasting seasons, daily prayers, and spiritual goals.
* **Library & Bible:** Access holy books, mezmurs, teachings of the fathers, and scripture.
* **Community:** Connect with other believers, share reflections, and build spiritual support.
* **Simple and Clean UI:** A modern, mobile-friendly design for easy navigation.
* **Multi-language Support:** Built with internationalization in mind (e.g., English and Amharic).

## Purpose of the Project

This project was created as part of a learning and development process. It focuses on combining **technology with spiritual practice**, demonstrating how software can support meaningful aspects of daily life.

The application structure was initially generated using a template from **Google AI Studio**, and the project is being further customized and developed manually.

## Technologies Used

* **React 18** - UI Library
* **TypeScript** - Type-safe JavaScript
* **Vite** - Frontend Tooling & Bundler
* **Tailwind CSS** - Utility-first styling
* **Lucide React** - Iconography

## Project Structure

```text
/
 ├── src/
 │    ├── components/    # Reusable UI components
 │    ├── views/         # Main application pages (Dashboard, Bible, Community, etc.)
 │    ├── types.ts       # TypeScript interfaces
 │    ├── constants.ts   # App constants and mock data
 │    ├── utils.ts       # Helper functions
 │    ├── App.tsx        # Main application entry point
 │    └── main.tsx       # React DOM rendering
 ├── index.html          # HTML template
 ├── package.json        # Dependencies and scripts
 ├── tailwind.config.js  # Tailwind CSS configuration
 └── vite.config.ts      # Vite configuration
```

## Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Open the project folder and install dependencies:
```bash
cd your-repository-name
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open the provided `localhost` link in your browser to view the app.
